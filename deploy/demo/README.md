# Watchfloor: public demo

Deployment bundle for the public demo of
[Watchfloor](https://github.com/triston-williamson/AI-analyst-workbench-for-air-and-sea-monitoring),
an AI-assisted maritime and air domain awareness workbench. It is generated by
`scripts/build_demo_bundle.py` in that repository; change the code there, not here.

The demo is the real operator console running on a **read-only snapshot** of six hours of live
Baltic Sea data (about 1,900 vessels and 140 aircraft):

- Ships (AIS) and aircraft (ADS-B) on a live map, coloured by type, with undersea cables and
  pipelines overlaid.
- Alerts from six detectors: going dark, loitering, ship-to-ship meetings, aircraft circling,
  OFAC sanctions matches and Isolation Forest anomalies. Click one to see its evidence trail,
  the sensor records it cites and its audit history.
- AI analyst reports drafted by Claude, where every factual sentence cites a sensor record.
  Open **AI REPORTS** below the map.
- Replay and traffic-density and dark-event heatmaps.

In this demo, Approve / Reject and AI report drafting are turned off, and there is no database
or API connection. The full system streams live data through Kafka into Snowflake.

Run it: `docker build -t watchfloor-demo . && docker run --rm -p 7860:7860 watchfloor-demo`,
then open http://127.0.0.1:7860. On Render, `render.yaml` defines a free web service.

Unclassified. Public data only; not affiliated with any government.
Data: AIS from aisstream.io; ADS-B from the OpenSky Network (non-commercial use);
OFAC SDN list (US Treasury); cables and pipelines from EMODnet Human Activities;
basemap © OpenStreetMap contributors, © CARTO.
